Über + kannst du bis zu 2 Codes eingeben. Jeder gültige Code verbindet dich automatisch mit seinem Ersteller.
Registrierungscode erzeugen um Freunde einzuladen
Klicke auf die grünen Generierungsfelder, um je
Feld einen R-Code zu erzeugen. Kopiere den
R-Code durch erneuten Klick auf das Feld und
lade so innerh. von 24 Stunden bis zu 2 Freunde
ein, indem du ihm/ihnen den Code weitergibst.
Dadurch entsteht zwischen Euch automatisch
eine Freundschaft auf SABBEL!

Jeder Code verliert entweder nach Verwendung oder nach Ablauf von 24 Stunden seine Gültigkeit. Er verschwindet dann aus dem Feld und du kannst durch Klick auf dieses einen neuen Code erstellen.
Wichtig:

Wenn du 2 Freunde einladen möchtest, sind diese in SABBEL NICHT automatisch miteinander befreundet!

Du schickst also z. B. Code 1 an Freund A und Code 2 an Freund B. Beide registrieren sich mit den beiden unterschiedlichen Codes. Die Codes werden nach ihrer jeweiligen Verwendung sofort ungültig.

In SABBEL bist du jetzt mit Freund A und Freund B befreundet – und beide sind mit dir befreundet. Freund A und Freund B sind untereinander aber noch nicht befreundet.

Aber dafür gibt es ja die Freundschaftsanfrage!
A muss B also eine Freundschaftsanfrage schicken. Meinetwegen auch andersherum! 😂

Kennen mehrere bereits registrierte Freunde denselben neuen Nutzer, kann jeder ihm einen eigenen Code schicken. Bei der Registrierung können über das + bis zu 2 Codes eingegeben werden. Jeder Code verbindet den neuen Nutzer automatisch mit dem Nutzer, der den Code erstellt hat und macht beide zu SABBEL-Freunden!

Anleitung
Nachrichten
Deine Nachrichten sind blau, die aller Anderen rot. Durch Klick auf deine Nachricht, kannst du sie sofort löschen.
Forum
Schreibe Nachrichten, die alle Freunde lesen können, denen du die Forum-Freigabe erteilt hast.
Forum-Freigabe
Hier bestimmst du, welche deiner Freunde deine Nachrichten im Forum lesen können. Die Freigabe kannst du jederzeit ändern.
Privatchat
Im Privatchat können nur du und der ausgewählte Freund eure Nachrichten sehen. Voraussetzung ist eine bestätigte Freundschaft.
Graues Namensfeld
Ein graues Namensfeld bedeutet: Mit dieser Person besteht noch keine Freundschaft.
Freundschaftsanfrage
Sende eine Freundschaftsanfrage, um einen Privatchat zu beginnen (Einmal auf ein graues Feld klicken). Wenn die andere Person zustimmt, seid ihr miteinander befreundet.
Freundschaft entfernen
Tippe zweimal auf das Namensfeld eines Freundes, um die Freundschaft zu beenden. Der Privatchat und die Forum-Freigabe werden dabei ebenfalls entfernt.
